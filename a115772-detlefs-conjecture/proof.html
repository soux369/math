A115772 ⊊ {x OR 4x}:
Detlefs's Conjecture on OEIS A115772 Is False

Proof note — November 27, 2026
Repository: github.com/soux369/a115772-detlefs-conjecture
Theorem. Let A115772 = { i : 13·i = C(21, i) }, where C is carryless (GF(2)[X]) multiplication (OEIS A048720). Then
A115772 ⊊ { x OR 4x : x ≥ 0 }.
The inclusion ⊆ holds, but the equality conjectured by Detlefs (2010) fails: 325 = 65 OR (4·65) satisfies 13·325 = 4225 ≠ 4097 = C(21, 325), so 325 ∉ A115772. The two sets agree below 325.

1  Disproof of the equality

Take x = 65 = 10000012. Then 4x = 260 = 1000001002 and i = x OR 4x = 1010001012 = 325. As integers, 13·325 = (26+1)2 = 212 + 27 + 1 = 4225, since 325 = 5·(26+1) and 13·5 = 26+1. In GF(2)[X], with 21 = 1 + X2 + X4 and 325 = (1 + X2)(1 + X6), the cross terms cancel: C(21, 325) = (1 + X2 + X4)(1 + X2)(1 + X6) = (1 + X6)2 = 1 + X12 = 4097. Hence 325 ∉ A115772. Direct computation shows the two sets coincide for all i < 325; the next counterexamples are 335, 365, 367, 485.

2  Proof of the inclusion

For the equation use the suffix state equation E(c, m, i) ⟺ c + 13i = m ⊕ C(21, i), with E(c, m, 0) ⟺ c = m. Splitting off the LSB b of i (13 and 21 are odd): E(c, m, i) ⟺ (c ≡ m mod 2) ∧ E(δeq((c,m), b), ⌊i/2⌋), where δeq((c,m), b) = (⌊(c + 13b)/2⌋, ⌊(m ⊕ 21b)/2⌋). For the right-hand side, bit j of x OR 4x is xj ∨ xj−2; the subset DFA over NFA states (xj−2, xj−1) has transition δDFA(S, b) = { (b₁, xj) : ∃b₀, (b₀, b₁) ∈ S ∧ (xj ∨ b₀) = b }. Running both machines in lockstep from ((0,0), {00}), exactly 24 pairs are reachable (16 with c ≡ m (mod 2), 8 boundary pairs with c ≢ m (mod 2)):

On all 24 pairs: closure — if c ≡ m (mod 2), both successors are again in the table; and terminal implication — c = m implies 00 ∈ S. Binary induction on i, reconstructing the witness x bit by bit through DFA predecessors, then gives: every i with 13i = C(21, i) is of the form x OR 4x. ∎

3  Verification

The result is formalized in Lean 4 (A115772Detlefs.lean, pure Lean 4.36.0, no Mathlib) and compiles with no errors and no sorry; #print axioms reports [propext, Classical.choice, Quot.sound] for the inclusion and the strictness, and [propext, Quot.sound] for the disproof. Independently, the 24-pair reachable set was recomputed by BFS from the definitions (the source of the table above), the terminal implication was checked on every pair, the counterexample and its minimality were verified directly, and the inclusion was brute-force checked for all i < 220 with no violation.
